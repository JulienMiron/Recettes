Ajouter une recette

Remplissez le formulaire, ou utilisez le favori « Ajouter recette » depuis un site de recettes (voir plus bas).

Un par ligne. Les quantités en début de ligne sont reconnues, pour pouvoir ajuster les portions.
Une étape par ligne. Une ligne qui commence par « ## » devient le titre de l'étape suivante. Une minuterie est ajoutée quand une durée est mentionnée.

Le favori « Ajouter recette »

Sur un site de recettes, ce favori lit la recette (la plupart des sites l'incluent dans un format standard) et ouvre cette page avec tout pré-rempli.

Installer sur Chrome (téléphone Android ou iPhone)
  1. Touchez Copier le code ci-dessous.
  2. Ajoutez cette page-ci aux favoris (menu ⋮ → ☆).
  3. Ouvrez le menu ⋮ → Favoris, appuyez longuement sur le nouveau favori → Modifier.
  4. Nom : Ajouter recette. Dans le champ URL, effacez tout et collez le code. Enregistrez.
Utiliser le favori
  1. Sur la page d'une recette, touchez la barre d'adresse.
  2. Tapez Ajouter recette et choisissez le favori (icône ☆) dans les suggestions. Il faut passer par la barre d'adresse : ouvert depuis la liste des favoris, il ne fonctionne pas.
  3. Vérifiez la recette ici, choisissez le type, puis Enregistrer.

Comment l'enregistrement fonctionne

Enregistrer ouvre la page « New issue » de votre dépôt sur GitHub, avec la recette déjà remplie. Touchez Create (ou Submit new issue) : en une à deux minutes, une GitHub Action ajoute la recette au site et ferme l'issue. Il faut être connecté à GitHub dans ce navigateur.

Seules les issues que vous ouvrez vous-même sont prises en compte. En cas de problème, l'Action laisse un commentaire dans l'issue.
